# CheckBill

CheckBill เป็น Android Application ที่สร้างขึ้นเพื่อแก้ปัญหาความยุ่งยากในการคิดเงินและหารค่าอาหารในกลุ่มเพื่อน โดยรองรับการหารแบบไม่เท่ากัน (แยกตามเมนูว่าใครทานอะไรบ้าง) พร้อมฟังก์ชันคำนวณ Service Charge และ VAT อย่างแม่นยำ

## ฟีเจอร์หลัก (Features)
- **เพิ่มรายชื่อเพื่อน (Party Members):** กำหนดสมาชิกที่ร่วมรับประทานอาหาร
- **เพิ่มเมนูอาหาร (Food Items):** ระบุชื่อเมนูและราคา
- **เลือกคนหารตามเมนู (Split by Item):** สามารถเลือกได้ว่าเมนูไหนใครเป็นคนรับประทานบ้าง (ไม่ต้องหารเท่ากันทุกเมนู)
- **คำนวณ Service Charge & VAT:** รองรับการตั้งค่าเปอร์เซ็นต์ Service Charge และภาษีมูลค่าเพิ่ม (VAT) ได้อย่างอิสระ
- **สรุปยอดสุทธิ (Bill Summary):** แสดงยอดรวมที่แต่ละคนต้องจ่ายอย่างชัดเจน ยุติธรรม พร้อมส่วนแบ่งเศษทศนิยมอย่างถูกต้อง

## เทคโนโลยีที่ใช้ (Tech Stack)
- **แพลตฟอร์ม:** Android App (Kotlin)
- **UI Framework:** Jetpack Compose UI
- **สถาปัตยกรรม & การนำทาง (Navigation):** ใช้สถาปัตยกรรมแบบ Multiple Activities และ `startActivity` ผสานกับ Intent Extras พิเศษผ่าน `kotlin-parcelize` เพื่อการเรียนรู้ Lifecycle และระบบนำทางพื้นฐานของระบบ Android อย่างเข้าใจง่าย
- **เครื่องมือการพัฒนา (IDE):** Android Studio / Gradle

## โครงสร้างหน้าจอ (Screens)
1. `MainActivity` - หน้าจอรับรายชื่อเพื่อน
2. `MenuActivity` - หน้าจอรับรายการอาหาร
3. `SplitActivity` - หน้าจอจับคู่คนกินกับเมนูอาหาร (Checkboxes)
4. `SummaryActivity` - หน้าจอสรุปผลลัพธ์การคำนวณยอดเงิน

## วิธีการใช้งานเบื้องต้น
1. เปิดแอปพลิเคชันขึ้นมาและเพิ่มรายชื่อทุกคนที่รับประทานอาหาร แล้วกดถัดไป
2. เพิ่มเมนูอาหารเครื่องดื่มที่สั่ง และราคาของแต่ละอย่าง
3. ในหน้ารายการอาหารที่สรุป ให้เลือกคนไขว้กับเมนูเพื่อระบุว่าใครรับประทานเมนูไหนบ้าง
4. หน้าระบบจะสรุปยอดเงินทั้งหมด ใส่ Service Charge และ VAT เพิ่มเติม (ถ้ามี)
5. ดูยอดเงินสรุปรายบุคคลที่ต้องจ่ายได้อย่างแม่นยำ!
